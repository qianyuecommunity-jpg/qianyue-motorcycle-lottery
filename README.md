# 社區機車位抽籤程式

純前端、無後端的社區機車位抽籤工具,專為部署到 **GitHub Pages** 設計。

## 功能

- **匯入 Excel 名單**:三欄式範本(機車格號 / 登記參與戶別 / 實際參與戶別)
- **戶別格式驗證**:戶號限 218~238 雙數、樓層限 1~13 樓,格式錯誤逐列回報
- **重複檢查**:同一欄位內若有重複值,匯入時擋下並指出列號
- **自動取交集**:合格戶 = 登記 ∩ 實到
- **動畫抽籤**:逐格滾動抽出,seed 與每籤紀錄全程顯示,log 自動捲到最新一筆
- **候補名單**:若合格戶數 > 車格數,超出的戶數以同一 seed 順位自動抽出「候補 1、候補 2 ⋯」
- **匯出 PDF**:點陣化 A4 報表,含抽籤結果、戶別對照、抽籤摘要(含 seed),公開可追溯且不易事後竄改
- **重新開始**:抽籤頁有單一按鈕清空所有狀態回到首頁(需二次確認),避免無痕重抽 seed
- **隱私**:全程在瀏覽器執行,不上傳任何資料

## 部署到 GitHub Pages

1. 把這個資料夾 push 到一個 GitHub repo(例如 `motorcycle-lottery`)
2. 在 repo 的 **Settings → Pages** 選擇 `Deploy from a branch`,branch 選 `main`、folder 選 `/ (root)`
3. 稍等 1-2 分鐘,網址就會是 `https://<你的帳號>.github.io/motorcycle-lottery/`

不需要 build step,所有檔案都是靜態的。`index.html` 為實際部署檔(已內聯各 jsx 區塊);獨立的 `*.jsx` 為來源鏡像,便於閱讀與後續編輯。

## 外部相依

由 CDN 載入,不打包:

- React 18.3.1 / ReactDOM / Babel Standalone(Babel JIT 轉 JSX)
- SheetJS(xlsx 0.20.1) — 匯入名單與下載範本
- jsPDF 2.5.1 + html2canvas 1.4.1 — PDF 匯出(不使用 `html2pdf` wrapper)

## 檔案結構

```
index.html         主要 HTML 殼,字型 + CSS + 內聯 script 區塊(部署檔)
app.jsx            根組件、狀態機(welcome / preview / drawing 三階段)
screens.jsx        Welcome 與 Preview 兩個畫面
drawing.jsx        Drawing 動畫頁(含結束時的 PDF 匯出按鈕)
excel-utils.jsx    Excel 匯入解析、範本下載、PDF 報表組裝
                   含 mulberry32 seeded PRNG + Fisher-Yates 洗牌
```

## Excel 範本格式

| 機車格號 | 登記參與戶別 | 實際參與戶別 |
|---------|-------------|-------------|
| 4       | 220號9樓     | 220號9樓     |
| 5       | 218號3樓     | 218號3樓     |
| 6       | 218號5樓     |             |
| ...     | ...         | ...         |

- 三欄長度可以不同,空白列會被忽略
- 每個儲存格匯入時自動 trim(去除前後空白,含全形空格)
- **標題列必須完全是**:`機車格號`、`登記參與戶別`、`實際參與戶別`(直接從範本下載最保險)
- **戶別格式**:`XXX號X樓`(例:`228號3樓`、`228號13樓`),戶號限 `218 220 222 224 226 228 230 232 234 236 238`,樓層 `1~13`(機車格號不受此限)
- **同一欄位內不可重複**;有任何格式錯誤或重複,匯入時會彈出錯誤訊息,逐列指出位置
- 首頁有「下載 Excel 範本」按鈕,內含格式說明 sheet,機車格號欄預設列出 `4–10`、`12–62`、`1左/中/右`、`2左/中/右`、`3左/中/右`、`106-1~4`、`108-1~4` 共 75 個車格

## 抽籤邏輯

1. 合格戶 = 登記名單 ∩ 實到名單(取交集,以 `Array.includes` / `Set` 嚴格比對)
2. 按下「開始抽籤」時以 `Math.random()` 生成一個 0~999,999 的 seed
3. 用 mulberry32(seed) 為 PRNG,對合格戶執行 Fisher–Yates 洗牌
4. 機車格號維持 Excel 原序;依索引配對:車格 #N → 洗牌後第 N 位合格戶
5. 若合格戶數 > 車格數 → 超出的合格戶接續以**候補 1、候補 2 …** 順序抽出(同一 seed,完全可重現)
6. 若車格數 > 合格戶數 → 多出的車格列為「無人認領」

抽籤結果完全由 (seed, 輸入名單, 程式版本) 三者決定,可重現、可離線驗證、可由 PDF 摘要欄位查核。

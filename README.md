# 社區機車位抽籤程式

純前端、無後端的社區機車位抽籤工具,專為部署到 **GitHub Pages** 設計。

## 功能

- **匯入 Excel 名單**:三欄式範本(機車格號 / 登記參與戶別 / 實際參與戶別)
- **自動取交集**:合格戶 = 登記 ∩ 實到
- **動畫抽籤**:逐格滾動抽出,過程透明、可暫停可跳過
- **匯出 PDF**:含結果、戶別對照、抽籤摘要(含 seed,可重現,且不易事後竄改)
- **可重抽**:每次抽籤產生新的亂數種子
- **隱私**:全程在瀏覽器執行,不上傳任何資料

## 部署到 GitHub Pages

1. 把這個資料夾 push 到一個 GitHub repo(例如 `motorcycle-lottery`)
2. 在 repo 的 **Settings → Pages** 選擇 `Deploy from a branch`,branch 選 `main`、folder 選 `/ (root)`
3. 稍等 1-2 分鐘,網址就會是 `https://<你的帳號>.github.io/motorcycle-lottery/`

不需要 build step,所有檔案都是靜態的。

## 檔案結構

```
index.html         主要 HTML 殼,字型 + CSS + script 載入順序
excel-utils.jsx    Excel 讀寫 / 範本下載 / 亂數種子
screens.jsx        Welcome 與 Preview 兩個畫面
drawing.jsx        Drawing 動畫 + Results 結果頁
app.jsx            根組件、狀態機
```

## Excel 範本格式

| 機車格號 | 登記參與戶別 | 實際參與戶別 |
|---------|-------------|-------------|
| 1       | 220-9F      | 220-9F      |
| 2       | 218-3F      | 218-3F      |
| 3       | 218-5F      |             |
| ...     | ...         | ...         |

- 三欄長度可以不同(空白列會被忽略)
- 重複值會自動去除
- 也可下載內建範本(首頁有按鈕)

## 抽籤邏輯

1. 合格戶 = 登記名單 ∩ 實到名單(取交集)
2. 將合格戶以亂數種子打散
3. 依車格順序逐一配對:第 N 格 → 第 N 位合格戶
4. 若合格戶數 > 車格數 → 多出的合格戶未中籤
5. 若車格數 > 合格戶數 → 多出的車格無人認領

抽籤結果完全由 seed 決定,可重現、可稽核。
